Solve2Git Privacy Policy

Last updated: September 15, 2026

Solve2Git is a Chrome extension that saves accepted LeetCode submissions to a GitHub repository selected by the user. This policy describes the data the extension handles and why.

Data handled

Solve2Git handles the accepted solution code, problem metadata (such as title, slug, language, and submission ID), GitHub account identity, the selected repository and branch, and the GitHub authorization token required to write the selected repository.

How data is used

The extension reads accepted-submission data only on LeetCode problem pages. It sends the solution code and related problem metadata only to the GitHub repository and branch the user explicitly selects. GitHub authorization is used only to list available repositories and branches and to create solution files.

Storage and sharing

GitHub authorization state, repository settings, and pending sync jobs are stored in Chrome extension local storage on the user’s device. Solve2Git has no separate backend, analytics service, advertising service, or data broker. It does not sell, rent, or share user data with third parties. The only external recipients are LeetCode, when the extension reads the active LeetCode page, and GitHub, when the user has selected a repository for syncing.

Security and retention

The extension communicates with LeetCode and GitHub over HTTPS. Data in local storage remains there until the user disconnects GitHub, removes the extension, or clears extension data. Files written to GitHub are controlled by the retention settings of the user’s GitHub account and repository.

Your choices

You can disable automatic syncing, retry or remove pending work by clearing extension data, disconnect GitHub from the extension settings, or uninstall the extension at any time. Disconnecting removes the stored GitHub authorization state and repository settings.

Changes to this policy

Material changes will be published on this page and reflected in the Chrome Web Store privacy disclosures before they take effect.

Contact

For privacy questions, contact the extension publisher through the support contact listed on the Chrome Web Store page.
